## 我的安装和配置过程
### github copilot
按照 GitHub 教程，在 VSCode 扩展商店安装 GitHub Copilot 扩展，然后登录 GitHub 账号后开启 Agent 模式；本地新建 Git 仓库（关联 GitHub 远程仓库），在仓库里写了一个带 bug 的 C 程序 bug.c，后续又在仓库根目录加了 AGENTS.md 作为项目规则文件。
### Cursor
从 cursor.com 下载安装并注册账号。一开始仓库只存在 GitHub 云端，Run on 里 This PC 是灰色不可选（Cloud Agent 要 Pro），所以用 Git: Clone 把仓库克隆到本地文件夹，再用 File → Open Folder 打开本地项目，Run on 选 This PC，就能用免费的本地 Agent；另外把本机 SSH 公钥 id_ed25519.pub 添加到 GitHub（Settings → SSH and GPG keys），配置好 git@github.com 的 SSH 连接。
